## BMAD Coding Standards Extension

### Documentation: Language-Appropriate Format

**Step 1** — Read `{project-root}/_bmad/data/active-coding-standards.md`.
**Step 2** — Detect language of the code being documented.
**Step 3** — Load:
1. `{project-root}/_bmad/data/style-guides/{provider}/{language}/SKILL.md`
2. `{project-root}/_bmad/data/style-guides/{provider}/{language}/{language}.md`
   (focus: documentation and comment format sections)

**Step 4** — Apply the guide's documentation format:
Javadoc structure, Python docstring style (Google vs. NumPy), comment conventions,
parameter/return documentation format.
